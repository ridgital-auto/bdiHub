# LinkHub

Dashboard kumpulan link web app — jalan di GitHub Pages.

- Proyek: wadah kumpulan link (tambah/edit/hapus proyek; hapus proyek memindahkan link ke "Tanpa proyek")
- Link: tambah/edit/hapus (nama, URL, deskripsi, proyek, pin), salin URL
- Filter chip per proyek + "Tanpa proyek", cari link
- Hitung jumlah dibuka, sematkan favorit
- Login Google + sinkron otomatis ke Drive: setiap perubahan tersimpan otomatis ke folder "LinkHub"/linkhub-backup.json di Drive akun yang login (±2,5 dtk setelah edit); saat login, data terbaru (berdasar waktu ubah) yang dipakai. Akun ridgitalstudio@gmail.com ditandai 👑 Admin.
- Export/import JSON manual tetap tersedia (format lama otomatis dimigrasi, kategori lama jadi proyek)

Live: https://ridgital-auto.github.io/linkhub/
